# ABA Claim Pre-Submission Audit Checklist

Use this checklist before sending a claim or when reviewing a denied claim.

## Claim Basics

- Client name or ID matches the authorization and clinical record.
- Date of service is correct.
- CPT code matches the service actually documented.
- Modifier is present and appropriate for payer/provider type.
- Place of service matches the note and authorization.
- Rendering provider is listed correctly.
- Supervising provider is listed when required.
- Diagnosis code is present and active.

## Authorization

- Authorization number is present.
- Date of service falls inside authorization period.
- CPT code is included on the authorization.
- Units billed do not exceed authorized remaining units.
- Location and provider type match authorization requirements.
- Frequency or daily limits are not exceeded.

## Eligibility

- Coverage was active on the date of service.
- Client is eligible for ABA/autism benefits under the plan.
- Referral, prescription, or order is on file when required.
- Coordination of benefits is resolved when another payer exists.

## Provider Credentialing

- Rendering provider credential supports the CPT code.
- Provider was active/credentialed with the payer on date of service.
- Supervision requirements are met and documented.
- NPI, taxonomy, and billing provider details are correct.

## Session Documentation

- Client presence is documented.
- Start and end time are documented.
- Total minutes support billed units.
- Location is documented.
- Provider signature is present.
- Session note identifies goals from the active treatment plan.
- Session note documents interventions used.
- Session note documents client response and objective data.
- Session note includes plan/next steps.

## CPT 97153 Direct Treatment

- Note reflects direct adaptive behavior treatment.
- Technician/RBT role is appropriate if applicable.
- Goals and interventions are from the active treatment plan.
- Data supports work performed during the session.

## CPT 97155 Protocol Modification

- Note identifies protocol reviewed or modified.
- Note explains why modification was clinically needed.
- Note includes data or client response that triggered review/change.
- Note documents provider direction, modeling, observation, or feedback when applicable.
- Note states what changed in the treatment protocol.
- Note includes future implementation instructions.

## CPT 97156 Caregiver Training

- Caregiver participation is documented.
- Training topic is linked to treatment plan goals.
- Provider documents coaching, modeling, feedback, or caregiver practice.
- Note documents caregiver response or performance.
- Client presence/absence aligns with payer rule.

## Denial Review

- CARC/RARC codes are captured.
- Payer narrative reason is captured.
- Denial category is assigned.
- Corrected claim, appeal, or write-off path is identified.
- Supporting documents are attached before resubmission.
